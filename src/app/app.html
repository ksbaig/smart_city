📖 How to Use

  1. Use the left sidebar to open map search, AI Agent, Dashboard, Legend, Reports and drawing tools.
  2. Search by ATM ID or Branch ID, then select a result to highlight it on the map.
  3. Use the AI Agent to run text or voice queries and display filtered ATM/branch results on the map.
  4. Open the Dashboard to view ATM and Branch performance summaries and detailed metrics.
  5. Switch the base map between Webmap and Satellite for different viewing contexts.
  6. Use the right panel for 3D scene, 360° view, CCTV, KROKI, reports and comments.
  7. Right-click the header to open Comments, this guide, or About.
  8. Use Comments to record and track notes. Data is saved locally and can be exported as JSON or TXT.

ℹ️ About

Smart City Network System

A map-based banking intelligence platform for ATM and branch operations in Riyadh.

  • ATM and Branch locator with interactive map search
  • Base map switching between Webmap and Satellite view
  • ATM Dashboard and Branches Dashboard with performance metrics
  • AI query assistant (text and voice) to filter and display results on map
  • Integrated 3D scene, 360° view, CCTV, reports and comments
