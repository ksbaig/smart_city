# CityPulse Smart City Demo

A lightweight, self-contained dashboard for demonstrating a connected-city concept. It includes illustrative city indicators, district conditions, service statuses, an energy chart, and community updates.

All figures and notifications are fictional sample content. This demo is not connected to sensors, city services, or live infrastructure.

## Run

Open `index.html` in any modern web browser. No installation, build step, or network connection is required.
