# Download Feature - Quick Start Guide

## 🚀 What's New

A **Download Button** is now available in the search results table. Click it to:
1. View feature details in a formatted side panel
2. Download a complete report as a text file

---

## 📋 How to Use

### Step 1: Search
```
Enter any query:
- "strong branches"
- "show all atms"
- "atms in Al Malaz"
- etc.
```

### Step 2: Click Download
```
Find the feature you want in the results table
Click the "Download" button (next to "Zoom")
```

### Step 3: View Details
```
Details panel appears below the table showing:
- Type (ATM or Branch)
- ID, Name, District
- Category, Performance Status
- Latitude, Longitude
- All properties
```

### Step 4: Download File
```
A text file is automatically downloaded:
  Filename: [Type]_Report_[ID].txt
  Example: Branch_Report_BR-20107.txt
```

### Step 5: Close Panel
```
Click the "×" button to close the details panel
```

---

## 📁 What Gets Downloaded

### File Name Format
```
[ATM or Branch]_Report_[Feature ID].txt

Examples:
- ATM_Report_ATM-12345.txt
- Branch_Report_BR-20107.txt
```

### File Contents
```
✓ Feature ID, Name, District
✓ Type and Category
✓ Performance Status (for branches)
✓ Location coordinates (Lat/Long)
✓ All GeoJSON properties
✓ Map information
✓ Usage instructions
✓ Timestamp and disclaimer
```

### File Format
```
- Text file (.txt)
- Can open in any text editor
- Human-readable format
- Well organized sections
```

## ❓ FAQ

### Q: Where does the file download?
**A:** To your browser's default download folder. Change in browser settings if needed.

### Q: Can I change the file name?
**A:** Files auto-download with names like `ATM_Report_[ID].txt`. You can rename after download.

### Q: What format is the file?
**A:** Plain text (.txt). Open in any text editor (Notepad, Word, etc.)

### Q: Can I download multiple features at once?
**A:** Yes! Download each one individually. Each creates a separate file.

### Q: Does it work on mobile?
**A:** Yes! The download and details panel work on all devices.

### Q: What information is in the downloaded file?
**A:** Complete feature details, location coordinates, all properties, metadata, and instructions.

### Q: Can I print the report?
**A:** Yes! Open the .txt file and use your print function (Ctrl+P or Cmd+P).

### Q: Is the data real?
**A:** No, this is synthetic demo data for testing. Real banking systems would use actual data.

## 📞 Getting Help

### Issue: Download button not showing
**Solution:** Make sure you have search results displayed

### Issue: File doesn't download
**Solution:** Check browser download settings or disable ad blocker

### Issue: Can't open downloaded file
**Solution:** Use any text editor (Notepad, Word, VS Code, etc.)

### Issue: Details panel not appearing
**Solution:** Try clicking Download button again, may just be loading
